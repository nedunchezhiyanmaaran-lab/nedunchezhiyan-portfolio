## 📊 Integrated Admin Intelligence Dashboard

Access the real-time analytics center directly from the portfolio:
- **Direct Route**: `/#admin` (e.g. `http://localhost:5173/#admin`)
- **Keyboard Shortcut**: `Ctrl + Shift + A` (or `Alt + A`)
- **Footer Trigger**: Click `Admin Analytics →` in the footer.
- **Security**: PIN-protected gate with instant unlock.

### Key Capabilities:
- **KPI Metrics**: Total Visitors, Pageviews, Average Session Dwell Time, Lead Conversion Rate.
- **Traffic Trends**: Interactive SVG Area Chart with daily hover tooltips.
- **Project CTR & Engagement**: Granular click-through and modal demo preview tracking.
- **CRM Lead Inbox**: Review, update pipeline status (`New` → `Contacted` → `Archived`), save internal notes, and direct mailto actions.
- **Audience & Technology**: Device breakdowns (Desktop/Mobile/Tablet), OS, Browsers, and Referral Sources (LinkedIn, GitHub, Direct, Google).
- **Owner Device Whitelisting**: Automatically detects developer IP / workstation to filter out self-visits from public metrics.

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Configure Environment Variables
Create a `.env` file in the root directory:
```env
VITE_SUPABASE_URL=https://cmzfnieekeckwkigyoew.supabase.co
VITE_SUPABASE_ANON_KEY=your_supabase_anon_key
```

### 3. Run Development Server
```bash
npm run dev
```

### 4. Build for Production
```bash
npm run build
```
